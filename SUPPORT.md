# Support

- Use [Discussions](https://github.com/appleweiping/splitproof/discussions) for usage questions and design ideas.
- Use [Issues](https://github.com/appleweiping/splitproof/issues) for reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/appleweiping/splitproof/security/advisories/new) for security concerns.

Support is best-effort. Public reports must use minimal synthetic records and include seed, algorithm version,
constraints, and relevant manifest metadata without disclosing private datasets.
