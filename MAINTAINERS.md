# Maintainers

SplitProof is currently maintained by [@appleweiping](https://github.com/appleweiping).

Maintainers review reproducibility, leakage guarantees, compatibility, performance, documentation, and release
evidence. Contributions are accepted through pull requests; a maintainer remains accountable for every merged change.

Security reports must use [private vulnerability reporting](https://github.com/appleweiping/splitproof/security/advisories/new).
